PROGRAMA DE TOMA DE DATOS SAR — ESCRITORIO

1. Extrae toda esta carpeta en una carpeta nueva. No ejecutes desde el ZIP.
2. Abre INICIAR_CUESTIONARIO.bat con doble clic.
   También puedes ejecutar: python cuestionario_ensayo.py
3. Elige tu base de datos XLSX y completa el formulario como antes.

El ajuste de compatibilidad de calculo se aplica automaticamente a cada
Excel nuevo. No tienes que ejecutar la herramienta de copias ni reparar
el archivo despues de generarlo. Se conservan los SAR de main12.
Sigue pendiente comprobar en tu Excel si este ajuste evita el cierre en AI.

Necesita Python 3.11 o posterior con tkinter. Si faltan dependencias, abre
una terminal dentro de esta carpeta y ejecuta:

    python -m pip install -r requirements.txt

Conserva la carpeta plantilla completa: contiene la información del Excel
original y las columnas ocultas. No necesitas buscar ni subir el datasheet.
La base de datos incluida es la última corregida; puedes elegir otra en el
formulario sin sustituir las plantillas.

La revisión corrige CC/CD de SAR y conserva la visibilidad de las columnas
originales. El detalle de las comprobaciones y sus límites está en:

    docs/revision_escritorio.md

Esta actualización corrige además las fórmulas COLUMN de WiFi que Excel
eliminaba al reparar, filtra las bandas de cada SAR por su certificación y
permite desplazarse por 2G-3G, LTE y 5G sin paneles inmovilizados incorrectos.
Genera de nuevo el ensayo para aplicar todas esas correcciones.

    docs/correccion_wifi_y_regiones.md

Si Excel se cierra al editar AI, el fallo sigue en investigacion. Esta revision
mantiene el calculo automatico sin forzar todos los calculos en cada entrada.
DIAGNOSTICO_CIERRE_EXCEL.bat guarda el error registrado por Windows en
Diagnostico_Excel.txt, para identificar el componente que provoca el cierre.

Esta entrega utiliza el cuestionario de escritorio. Incluye todo lo necesario
para generar; excluye entornos Python, cachés y ejemplos Excel antiguos.
